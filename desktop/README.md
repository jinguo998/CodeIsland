# CodeIsland Desktop

CodeIsland's Windows shell uses Tauri 2 and React. The app and hook client load a native library built from the original files in `Sources/CodeIslandCore`. These files handle hook normalization, tool steps, attention decisions, reminders, Claude usage and quotas, and request formatting for the seven built-in push services. The Windows installers include the Swift runtime.

## Prerequisites

- Windows 10/11 (WebView2 is installed by the Tauri installer/bundler)
- Node.js 20+ and npm
- Swift 6.2.3 or later and Python 3 for native builds (`winget install --id Swift.Toolchain -e`)
- Rust stable (`rustup default stable`) with the MSVC toolchain
- Visual Studio Build Tools with the "Desktop development with C++" workload
- WebView2 runtime (present on current Windows; the Tauri docs have the
  evergreen bootstrapper)

## Build and run

### WSL source, Windows build mirror

Rust/Tauri builds are most reliable from Windows, so keep the source in WSL and
mirror it to a Windows-visible directory before building:

```bash
# from the repository root (WSL)
desktop/scripts/sync-to-windows.sh
# -> /mnt/c/dev/CodeIsland/desktop
```

Then, in Windows PowerShell:

```powershell
cd C:\dev\CodeIsland\desktop
npm ci
.\scripts\prepare-sidecar.ps1   # builds codeisland-hook.exe / codeisland.exe sidecars
npm run tauri dev        # dev shell with hot reload
npm run tauri build      # production build + NSIS/MSI bundles
```

For a complete release (bundles + SHA-256 manifest):

```powershell
.\scripts\build-release.ps1
```

Re-run `sync-to-windows.sh` after changing Swift or Rust sources or Tauri configuration. The
script excludes `node_modules`, `dist` and `target`.

### Frontend-only development (WSL or Windows)

```bash
cd desktop
npm ci
npm run dev              # Vite on http://localhost:1420
```

### Release build

On Windows:

```powershell
pwsh -NoProfile -File .\scripts\build-release.ps1
```

The script runs `npm ci`, the frontend build and the Tauri build, copies the
NSIS/MSI bundles into `desktop/artifacts/`, computes SHA256 hashes and writes
`artifacts/release-manifest.json`.

CI runs the original Swift tests on macOS, Linux and Windows, and exercises the Rust callers on Linux and Windows. It extracts the Windows NSIS installer and loads the packaged Swift library with only its bundled dependencies and system DLLs available. Release tags also build an MSI.

## Tests

Linux native tests require Swift and the SQLite development headers (`libsqlite3-dev` on Ubuntu).

```bash
# Frontend typecheck + bundle
cd desktop && npm run build

# Core crates (fast, no Tauri/WebView dependencies)
cd desktop/src-tauri
cargo test -p codeisland-domain -p codeisland-agents -p codeisland-ipc -p codeisland-runtime

# Everything (Windows)
cargo test --workspace

# Advanced integrations, including feature-gated managers
cargo test -p codeisland-integrations
cargo test -p codeisland-integrations --features ble,ssh,lan
```

## Architecture

| Path | Role |
| --- | --- |
| `src/` | React UI, typed bindings generated by `ts-rs` |
| `src-tauri/src/` | Tauri app, commands, tray/window wiring |
| `src-tauri/crates/codeisland-domain` | Pure domain types, attention policy, session store |
| `src-tauri/crates/codeisland-agents` | Agent definitions, hook install/repair, event normalization |
| `src-tauri/crates/codeisland-ipc` | NDJSON named-pipe client/server |
| `src-tauri/crates/codeisland-runtime` | Runtime state machine, persistence, IPC wiring |
| `src-tauri/crates/codeisland-hook` | One-shot hook client (`codeisland-hook`) |
| `src-tauri/crates/codeisland-cli` | `codeisland` installer/doctor/diagnostics CLI |
| `src-tauri/crates/codeisland-integrations` | Push, BLE Buddy, SSH, LAN and quota integrations |

`CONTRACTS.md` documents the public API every crate must keep.

## Integrations and feature flags

`codeisland-integrations` exposes its pure protocol code unconditionally and
gates only the platform-heavy managers:

| Feature | Enables | Default |
| --- | --- | --- |
| `ble` | `BuddyManager` over `btleplug` (ESP32 Buddy LCD) | off |
| `ssh` | `SshManager` over `russh`/`russh-sftp` | off |
| `lan` | `LanServer` (axum) for `GET /api/state`, `POST /api/pair`, `POST /api/action` | off |

Without a feature the manager is still exported and returns `Unsupported`.
Push notifications and the local Claude quota scanner need no feature flag;
their dependencies are part of the crate's base manifest.

```bash
# Example: build the app with all integrations
cd desktop/src-tauri
cargo build -p codeisland-integrations --features ble,ssh,lan
```

The LAN server binds `0.0.0.0:0` (ephemeral port), is off by default, and
returns a pairing code. Clients exchange that code at `POST /api/pair` for an
HMAC token used on `POST /api/action`. Pairing state is in-memory only.

## CLI

```bash
codeisland hooks status
codeisland hooks install --agent claude
codeisland hooks repair
codeisland hooks uninstall --agent codex
codeisland doctor
codeisland diagnostics --out diagnostics.json
codeisland send --source claude --event PermissionRequest --file event.json
codeisland version
```

`send` validates the JSON and hands it to the resolved `codeisland-hook`
binary (`CODEISLAND_HOOK` override, else beside the CLI, else on `PATH`),
setting `CODEISLAND_SOURCE` and `CODEISLAND_EVENT` for the hook.
